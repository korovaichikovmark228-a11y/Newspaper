# The Startup Times 📰

Ежедневная газета о стартапах, IT и ИИ в вёрстке в духе NYT.
**PWA** — устанавливается на домашний экран iPhone и **работает офлайн**.
Каждое утро в 9:00 агент собирает свежие новости и обновляет выпуск.

## Разделы
- **IT и стартапы — мир**
- **IT и стартапы — Россия**
- **Искусственный интеллект**
- **Полезные интеграции**
- **Советы: стартапы и вайбкодинг**

## Структура

```
index.html              — страница газеты
css/style.css           — вёрстка (NYT-стиль, адаптив, мобильная версия)
js/app.js               — рендер выпуска + архив + офлайн-фолбэк
data/news.json          — ← ДАННЫЕ ТЕКУЩЕГО ВЫПУСКА (агент перезаписывает каждый день)
data/seq.txt            — счётчик номера выпуска (лёгкий, чтобы агент не читал весь JSON)
data/archive/index.json — список прошлых выпусков (пополняется автоматически)
data/archive/<дата>.json— сохранённые прошлые выпуски
sw.js                   — Service Worker (офлайн-кэш: оболочка + все data/*.json)
manifest.webmanifest    — манифест PWA
icons/                  — иконки для установки
agent/generate.md       — бриф для ежедневного агента (что и как собирать)
tools/gen_icons.py      — генератор иконок (запускать при желании сменить лого)
```

Архив: кнопка «📚 Предыдущие выпуски» внизу газеты открывает список прошлых
номеров. Каждое утро агент архивирует уходящий выпуск в `data/archive/` и
добавляет запись в `index.json`. Изначально список пуст.

Как это работает: приложение грузит `data/news.json`. Service Worker кэширует
оболочку (cache-first) и данные (network-first → офлайн-фолбэк). Открыл с
интернетом — получил свежий выпуск и он сохранился; открыл без интернета —
показывается последний загруженный.

## Запуск локально

```bash
python -m http.server 8000
# открыть http://localhost:8000
```
(Service Worker и установка PWA требуют `https://` или `localhost`.)

## Публикация (GitHub Pages)

1. Запушить репозиторий на GitHub.
2. **Settings → Pages → Source: `Deploy from a branch` → `main` / `root`**.
3. Через минуту газета будет доступна по адресу
   `https://<user>.github.io/Newspaper/`.

## Установка на iPhone

1. Открыть адрес GitHub Pages в **Safari** (именно Safari).
2. Кнопка **«Поделиться»** → **«На экран „Домой“»** → **Добавить**.
3. Иконка «Startup Times» появится на домашнем экране; запускается на весь
   экран и открывается офлайн.

## Ежедневное автозаполнение в 9:00

Наполнением занимается агент по брифу [`agent/generate.md`](agent/generate.md):
собирает новости веб-поиском, переписывает `data/news.json`, коммитит и пушит —
GitHub Pages пересобирается, iPhone подтягивает выпуск при следующем открытии.

Настраивается как ежедневная задача (routine) в Claude Code с расписанием
`0 9 * * *` в нужном часовом поясе.
